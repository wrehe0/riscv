# RISCV_8481
RISC-V kernel Education

Проект по построению ядра ОС на базе RISC-V процессора.
Основная работа идет в Linux под эмулятором QEMU с кросскомпиляцией.

Пока проект развивается по коммитам, в дальнейшем возможно будет переведен в последовательные уроки, разнесенные по директориям.
Да, с ИИ в обнимку, да, копипаст, ... но доведенный до устойчиво-повторяемого состояния.

Нужен для того, чтобы показать цепочку рассуждения и то, что низкоуровневая работа -- при должной аккуратности -- это интересно и увлекательно.


RISC-V -- Процесс создания ядра
CI-CD -- Процесс сопровождения и автоматизации разработки 

PROGRESS.md -- Отдельный файл с прогрессом развития проекта.
